# Roadmap

## Phase 1: Product skeleton

- Create the web shell and branding
- Add the AI service health endpoint
- Define shared document types
- Decide local development workflow
- Make both services runnable on a fresh machine

## Phase 2: Ingestion pipeline

- Upload documents from the web app
- Persist metadata and file references
- Queue background processing jobs
- Track job state transitions

## Phase 3: Understanding and retrieval

- Add OCR and layout extraction
- Store chunks and embeddings
- Support semantic search
- Add grounded question answering with citations

## Phase 4: Structured extraction

- Define extraction schemas
- Extract key-value fields from documents
- Score confidence and expose review flows
- Build evaluation datasets and regression checks

## Phase 5: Production polish

- Add authentication
- Improve monitoring and error handling
- Add usage analytics and cost tracking
- Harden tests and deployment workflows
